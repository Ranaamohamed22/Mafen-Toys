 ### Maven Toys - Power BI Analysis
## 📌 Project Overview
This project analyzes sales, inventory, profitability, and stockout performance for a toy store using Power BI.

The dashboard helps identify:
- Sales performance across locations
- Most profitable products and categories
- Inventory availability
- Lost revenue caused by stockouts

---

## 🎯 Business Problem
One of the biggest challenges for retail stores is losing sales because products are unavailable when customers want to buy them.

This project focuses on analyzing:
- Which products frequently go out of stock
- Which store locations are most affected
- Estimated lost revenue due to stockouts
- Overall sales and profit performance

---

### Tools Used
- Power BI
- Power Query
- DAX
- Data Modeling
- Data Cleaning

---

### Data Preparation
Before starting the analysis, the dataset was cleaned and prepared by:
- Removing duplicate records
- Handling missing values and errors
- Correcting data types
- Building relationships between tables

---

## 📊 Dashboard Pages

### 1️⃣ Sales Overview
- Sales analysis by city and store location
- Monthly sales trends
- Store performance comparison

### 2️⃣ Products Analysis
- Most profitable categories and products
- Stock on hand analysis
- Product cost and availability insights

### 3️⃣ Stockout Insights
- Categories with the highest stockout cases
- Lost revenue estimation
- Most affected store locations
- Products causing the biggest losses

---

## 💡 Key Insights
- Stockouts had a direct impact on revenue and customer purchasing behavior.
- Some products generated high demand but suffered from low inventory availability.
- Certain locations experienced more stockout issues than others.
